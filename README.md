# Данные для проекта «Менеджер расходов и бюджета»

- `transactions.csv` — симуляция транзакций пользователя (доходы/расходы по категориям). 
  Данные сгенерированы на основе структуры потребительских расходов населения РФ (по данным Росстата) за май 2026 года.
- `currency_rates.csv` — реальные курсы валют USD/RUB с официального сайта Банка России (ЦБ РФ) за май 2026 года.

**transactions.csv:**
- `date` — дата транзакции
- `category` — категория расхода (Продукты, Транспорт, Жильё и т.д.)
- `amount` — сумма
- `currency` — валюта
- `description` — описание/место покупки

**currency_rates.csv:**
- `date` — дата курса
- `base_currency` — исходная валюта
- `target_currency` — целевая валюта
- `rate` — курс
